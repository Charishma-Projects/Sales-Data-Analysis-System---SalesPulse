Remote API Integration Examples:
Bash / cURL (Fetch Analytics):
curl -X GET "http://127.0.0.1:5000/api/analytics" \
  -H "X-API-Key: YOUR_PUBLIC_KEY"
cURL (Upload Dirty CSV → Download Cleaned CSV directly):
curl -X POST "http://127.0.0.1:5000/api/clean-csv?format=file" \
  -H "X-API-Key: YOUR_PUBLIC_KEY" \
  -F "file=@sales_dirty.csv" \
  -o "sales_cleaned.csv"
Python requests:
import requests
res = requests.get("http://127.0.0.1:5000/api/analytics", headers={"X-API-Key": "YOUR_PUBLIC_KEY"})
print(res.json()["analytics"]["summary_kpis"])
